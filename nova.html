NOVA

Neural Optimized Vector Architecture

A hybrid state-space model architecture with an integrated knowledge graph, template-augmented generation and Hebbian instant learning — designed as an alternative to pure attention-based models for small, local inference.

How it works Patent status
Architecture

A linear-time pipeline

NOVA combines state-space sequence modelling with graph-based knowledge retrieval, so sequence cost grows linearly with input length rather than quadratically as in attention-based designs.

Input
→
Tokenization
→
State-space model
→
Knowledge graph
→
Output

State-space layer

Sequence modelling with linear-time complexity in sequence length, rather than the quadratic cost of full self-attention.

Knowledge graph layer

Graph traversal with breadth-first search and path scoring for multi-hop relational lookups at inference time.

Template layer

Slot-fill generation for structured, repeatable outputs where free-form generation is unnecessary.

Feed-forward layer

Standard dense transformation stage between the sequence and output stages.

Hebbian learning loop

Instant association updates at inference time, without a full retraining cycle.

CPU target

The design targets ordinary processors and edge hardware rather than datacenter accelerators.

Inference Modes

Pipelines that activate only the layers they need

Rather than running every layer for every request, NOVA routes a prompt to the pipeline that suits it. The modes below describe what each pipeline does.

Available

Token generation

Autoregressive text generation through the state-space layers.

Available

Graph reasoning

Traverses the knowledge graph for multi-hop relational queries and entity lookups.

Available

Template rendering

Slot-fill generation from predefined templates for structured output.

Available

Hybrid mode

Combines sequence, graph and template layers based on prompt analysis.

Beta

Reasoning engine

Classifies a question into one of seven types — mathematical, causal, debug, plan, compare, code generation, general — builds a step-by-step chain and returns a confidence score.

Beta

Decision engine

Q-learning with energy scoring to rank candidate actions without additional neural overhead.

Experimental

Swarm intelligence

Independent agents propose solutions, vote on outcomes and adapt strategies over time.

Experimental

Energy scoring

Boltzmann-style scoring with entropy-based evaluation to select among candidate outputs.

Available

Translation

Cross-lingual transfer using aligned vector spaces with graph-backed vocabulary.

Status

What NOVA is today

Shipping

The model in the NC binary

The model that ships inside NC today is approximately 5M parameters and around 20MB on disk. It runs on CPU with no GPU requirement and no cloud account. Larger configurations are a research direction, not a released product line.

Quick Start

Run it locally

NOVA ships inside the NC runtime. Install NC and the engine is already present.

# install the NC runtime
curl -fsSL https://nc.devheallabs.in/install.sh | sh

# check the AI engine
nc ai status

# generate from a description
nc ai generate "a REST API for users"
