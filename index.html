Generation

A full project from one command Beta

The current v1 release binary is validated to turn a complex English prompt into a complete NC Lang and NC UI scaffold, with semantic coverage for tenants, roles, analytics, approvals and alerts.

nc ai create "multi-tenant operations dashboard with role based
        access, analytics, alert center, approvals and dark theme"

# observed output
Engine: built-in model (loaded)
Created: service.nc      # backend scaffold
Created: app.ncui        # dark-theme NC UI page
Created: test_app.nc     # tests
Created: README.md       # docs
Created: dist/app.html   # compiled bundle

Validated on Windows PowerShell and the shell-path harness, using the built-in model with an explicit template fallback and semantic smoke checks.

Reasoning Engine

Think, don't just generate Beta

A logic-first reasoning engine written in NC. It classifies a question, builds a step-by-step reasoning chain and returns an answer with a confidence score — structured reasoning rather than free-form token generation.

nc run nc-ai/reason-ai/reason.nc -b demo

Q: "If a train travels 60 km in 1 hour, how long for 180 km?"
   Type:       mathematical
   Detected:   travel / distance problem
   Formula:    time = distance / speed
   Confidence: 0.85
Distillation

Learn from a teacher model Experimental

NC AI can distil knowledge from an external model into its own built-in 5M-parameter model, training it to better follow NC Lang and NC UI patterns. After distillation it continues to run offline on your CPU.

How it works

NC code prompts go to an external teacher model; the student model trains on the responses and absorbs the patterns.

Offline afterwards

Once distilled, generation runs entirely on your own machine — no API key and no recurring cost.

Install

Get started in seconds

NC AI ships inside the NC binary. Install NC and the engine is already there.

# install NC (includes the AI engine)
curl -fsSL https://nc.devheallabs.in/install.sh | sh

# create your first app
nc ai create "a todo app with auth and dark theme"

# or generate a snippet
nc ai generate "a REST API for users"

# check engine status
nc ai status
NC-Native

Written in NC

Only the inference engine is C. Generation, training, error-fix, review and export are all written in NC itself — the language using its own tooling.

nc ai review

Code review with best-practice, security and performance notes, plus a quality score.

nc ai check

Validates NC code and repairs missing declarations and syntax errors automatically.

nc ai export

Export a project as a standalone binary, container image, archive or NC package.
